# Overview基础知识

## 一、HPC 与几种计算形态

**高性能计算 HPC，High Performance Computing**，是计算机科学中的一个重要方向，目标是研究复杂体系结构、并行算法和相关软件，从而让计算机系统具备更强的计算能力。HPC 常用于科学计算、工程仿真、人工智能、大规模数据处理等场景。

HPC 相关的几个概念要区分清楚：

**并行计算 Parallel Computing**：
 多个计算资源同时处理任务，以缩短运行时间。它可以发生在一台多核机器内部，也可以发生在由网络连接的多台机器之间。过去很长时间里，并行计算几乎就是 HPC 的核心手段。

**分布式计算 Distributed Computing**：
 由多个物理上独立、可能地理上分散的计算机协同工作。重点不只是“快”，还包括异构性、开放性、安全性、可伸缩性、并发性、透明性和故障处理。

**集群计算 Cluster Computing**：
 用高速网络把多台高性能工作站或服务器连接起来，对外表现得像一个统一的计算资源。集群本质上是一种并行或分布式系统，是性价比很高的 HPC 方案。

**云计算 Cloud Computing**：
 由网格计算、分布式计算、虚拟化、网络存储等技术发展而来。它的核心不是单纯追求最高性能，而是把计算资源包装成服务，按需供应、按量付费。可以把云平台理解成“计算资源自来水厂”：用户需要时申请虚拟机、存储、网络等资源，不必关心底层物理机器在哪里。

**异构并行计算**：
 不同类型的处理器协同工作，例如 CPU + GPU、CPU + FPGA、CPU + MIC。HPC 和 AI 中非常常见，因为不同硬件擅长不同类型的计算。

## 二、计算机与计算系统

计算机可以理解为：**具有程序能力的数据处理机**。
 程序就是按照预定步骤处理数据的算法实现。

计算机中的所有信息都要被数字化，最终以二进制位模式表示。也就是说，不论是整数、小数、文字、图片、声音还是视频，在计算机底层都是一串 0 和 1。

现代计算机的基本模型是 **冯·诺依曼计算机模型**。它的关键思想是：

程序和数据都存放在存储器中；CPU 从存储器中取指令；CPU 对指令进行译码；CPU 执行指令；执行过程中可能读写内存或外设。

CPU 的基本工作循环可以概括为：

**取指令 → 分析/译码指令 → 执行指令**

计算机系统由两大部分组成：

**硬件系统**：处理器、存储器、输入设备、输出设备、外部设备等。
**软件系统**：系统软件和应用软件。系统软件包括操作系统、编程语言、工具软件等；应用软件包括办公软件、浏览器、游戏、科学计算软件等。

计算机启动的大致过程：

通电后，CPU 执行 BIOS/UEFI 中的启动程序；
 BIOS/UEFI 找到启动设备；
 启动装载程序把操作系统调入内存；
 操作系统接管计算机，负责管理硬件和软件资源。

## 三、计算机中数的表示

### 1. 整数表示

计算机中正负数通常使用一个符号位表示。一般约定：

符号位 0 表示正数；
 符号位 1 表示负数。

例如用 5 位机器数表示：

+1011 可以写成 `01011`
 -1011 可以写成 `11011`

这里最高位是符号位，后面是数值部分。

整数的机器表示常见有三种：**原码、反码、补码**。

### 2. 原码

原码就是符号位加数值位。

正数：符号位为 0，数值位不变。
 负数：符号位为 1，数值位表示绝对值。

原码的优点是简单、直观，适合理解乘法。比如计算 `2 × (-3)` 时，可以先忽略符号算 `2 × 3 = 6`，再根据符号判断结果为负数。

但原码不适合直接做加减法，因为符号位和数值位需要分开处理。

### 3. 反码

正数的反码等于它本身。
负数的反码：符号位保持 1，数值位逐位取反。

例如：

`+1010010` 的反码是 `01010010`
 `-1010010` 的反码是 `10101101`



### 4. 补码

正数的补码等于原码。
 负数的补码等于反码加 1。

例如：

`+1010010` 的补码是 `01010010`
 `-1010010` 的反码是 `10101101`，补码是 `10101110`

补码是计算机中最重要的整数表示方式，因为它可以把减法转化成加法，并且符号位可以和数值位一起参与运算。

例如 5 位二进制中：

`a = 11`，补码为 `01011`
 `b = -10`，原码 `11010`，反码 `10101`，补码 `10110`

计算 `11 + (-10)`：

```
  01011
+ 10110
=100001
```

最高位进位丢弃，得到：

```
00001
```

结果为 1。

补码还有一个重点：
 n 位补码能表示的范围是：

```
-2^(n-1) 到 2^(n-1)-1
```

比如 8 位补码范围是：

```
-128 到 127
```

## 四、定点数与浮点数

计算机不仅要表示整数，还要表示小数，例如 0.1、3.14、-5.888。

主要有两种方式：

**定点数**：小数点位置固定。
 可以是定点纯整数，也可以是定点纯小数。优点是简单，缺点是表示范围有限。

**浮点数**：类似科学计数法。
 一个浮点数通常由符号位、阶码和尾数组成。

阶码表示小数点的位置，类似科学计数法中的指数；
 尾数表示有效数字。

浮点数的优点是表示范围大，适合科学计算；缺点是精度有限，很多十进制小数不能被二进制精确表示，例如 0.1 通常不能被精确存储。

## 五、编码与文本表示

计算机中的文本也是二进制数据。文本中的每一个字符，都要对应一个唯一的二进制编码。

### 1. ASCII

ASCII 是英文字符编码标准，全称是：

**American Standard Code for Information Interchange**

它主要用于英文字符，包括英文字母、数字、标点和控制字符。

ASCII 有 7 位形式和 8 位扩展形式。
 7 位 ASCII 可以表示 128 个字符。

### 2. Unicode

Unicode 是通用字符集，目标是表示世界上几乎所有书写系统的字符，也叫统一码、万国码。

注意：**Unicode 是字符集，UTF-8 / UTF-16 / UTF-32 是编码方案。**

常见编码方式：

**UTF-8**：兼容 ASCII，英文通常占 1 字节，中文通常占 3 字节。
 **UTF-16**：常用 2 字节或 4 字节表示字符。
 **UTF-32**：固定使用 4 字节表示字符，空间开销大。

### 3. 汉字编码

汉字编码是为了让计算机能够处理、显示、打印和交换汉字。

常见标准：

**GB2312-1980**：收录简化汉字 6763 个，总字符 7445 个。
 **BIG5**：港澳台地区常用繁体汉字编码。
 **GBK**：GB2312 的扩展，收录 2.1 万多个汉字。
 **GB18030**：GBK 的升级版，覆盖更广，是中国国家标准。

汉字处理过程中有几类编码：

**输入码**：输入法使用的编码，例如拼音、五笔。
 **交换码**：用于不同系统之间交换信息。
 **机内码**：计算机内部实际存储和处理的编码。
 **字形码**：用于显示或打印汉字的字形信息。

字形表示有两种主要方式：

**点阵字形**：把汉字分解成点阵，比如 16×16 点阵。16×16 位 = 256 位 = 32 字节。
 **矢量字形**：用轮廓和数学指令描述字符形状，例如 TrueType 字体。

## 六、多媒体数据表示

多媒体包括文本、图形、图像、音频、视频等。它们在计算机中本质上也都是二进制位模式。

### 1. 图形与图像

图形通常指几何线条、几何符号等；图像通常指由像素组成的图片。实际处理中二者经常混用。

主要有两种表示技术：

**位图 / 光栅图 Raster Graphics**：
 使用像素阵列表示图像。每个像素是一个点，像素数量与分辨率有关。颜色常用 RGB 表示。位图放大后容易失真。

**矢量图 Vector Graphics**：
 用数学公式描述直线、曲线和形状。放大缩小时更平滑，不容易失真，适合图标、字体、工程图等。

### 2. 音频

音频包括声音和音乐。计算机处理音频时，需要把连续的模拟声音转化为数字信号。核心过程包括采样、量化和编码。

### 3. 视频

视频是图像的动态过程，本质上是一帧帧图像连续播放。
 视频数据量很大，因此通常要压缩存储，播放时再解压。

MPEG 是一系列音视频编码和压缩标准，例如 MPEG-1、MPEG-2、MPEG-4 等。

## 七、计算机系统组成

计算机硬件系统主要包括：

处理器；
 存储器；
 输入输出系统；
 系统总线和接口。

### 1. 主板与芯片组

PC 机的大多数功能电路安装在主板上。传统主板中常提到“北桥”和“南桥”。

北桥主要负责 CPU、内存、高速总线等核心部件之间的数据通信；
 南桥主要负责外设接口、低速设备等。

现在很多功能已经被集成到 CPU 或芯片组中，但理解北桥/南桥有助于理解计算机内部连接关系。

### 2. NUMA

NUMA 是 **Non-Uniform Memory Access**，非统一内存访问。
 在多 CPU / 多节点系统中，某个 CPU 访问本地内存会更快，访问远端内存会更慢。

这在 HPC 中很重要，因为线程或进程如果频繁访问远端内存，会导致性能下降。实际优化中常见“绑核”“内存亲和性”等问题。

------

## 八、处理器 CPU

处理器由 **运算器** 和 **控制器** 构成。

从逻辑上看，CPU 包括：

**运算器 ALU**：执行算术运算和逻辑运算。
 **控制器 Controller**：产生控制信号，控制指令执行。
 **数据寄存器 Data Register**：保存运算数据。
 **指令寄存器 IR**：保存当前要执行的指令。
 **程序计数器 PC**：保存下一条指令的地址。
 **地址电路**：产生和输出地址信号。

CPU 执行程序的基本过程：

```
取指令 → 指令译码 → 执行指令 → 更新 PC → 继续下一条指令
```

### 总线

总线是一组公共信号线，用来连接 CPU、内存和 I/O 控制电路。

总线主要分三类：

**数据总线**：传输数据。
 **地址总线**：传输地址信号。
 **控制总线**：传输读、写、中断等控制信号。

### CPU 性能指标

常见指标包括：

**主频**：单位 GHz，表示时钟频率，但主频不等于真实性能。
 **MIPS**：每秒执行百万条指令数。
 **集成度**：芯片内晶体管数量。
 **字长**：CPU 一次能处理的最大二进制位数，例如 32 位、64 位。
 **缓存**：L1、L2、L3 Cache，缓存越有效，CPU 等内存的时间越少。
 **功耗和温度**：高性能处理器必须考虑散热和能耗。

### CISC 与 RISC

**CISC，复杂指令集计算机**：
 指令数量多，指令功能复杂。典型例子是 x86 系列处理器。优点是指令表达能力强，缺点是硬件控制逻辑复杂。

**RISC，精简指令集计算机**：
 指令数量较少，指令格式规整，执行时间较统一，便于流水线设计。典型例子包括 ARM、RISC-V、SPARC 等。

考试中常见区分点：

CISC：复杂指令，硬件复杂，单条指令功能强。
 RISC：简单指令，执行规整，利于流水线和优化。

## 九、存储器系统

存储器用于保存程序和数据。计算机中的存储单位以字节为基础。

```
1 Byte = 8 bit
1 KB = 2^10 B
1 MB = 2^20 B
1 GB = 2^30 B
1 TB = 2^40 B
```

注意：计算机系统中 KB、MB、GB 常按 2 的幂计算，而日常近似中也会用 10³、10⁶、10⁹ 表示。

### 1. 内存

内存也叫主存，直接通过总线与 CPU 交互，速度比外存快，但容量较小。

常见内存类型：

**RAM，随机存取存储器**：易失性，断电后数据丢失。
 RAM 又分为 DRAM 和 SRAM。

DRAM：动态 RAM，容量大、成本低，常用作主存。
 SRAM：静态 RAM，速度快、成本高，常用作缓存 Cache。

**ROM，只读存储器**：非易失性，断电后数据不丢失。
 常用于存放 BIOS/UEFI 等固件。

ROM 又可分为：

PROM：写入后不能修改。
 EPROM：可用紫外线擦除后重新写入。
 EEPROM：可电擦除、可重新编程。

### 2. 存储系统层次

存储器层次结构大致是：

```
寄存器 → Cache → 主存 RAM → SSD/HDD → 光盘/磁带等
```

越靠近 CPU，速度越快，容量越小，单位价格越高；
 越远离 CPU，速度越慢，容量越大，单位价格越低。

### 3. 外存

外存用于长期保存数据，例如硬盘、SSD、U 盘、光盘等。

**固态存储器 SSD / Flash**：
 基于半导体存储，没有机械结构，速度快、低功耗、抗震，断电后数据不丢失。

### 4. 主存—辅存结构与虚拟存储

程序和数据通常长期存放在外存中。程序运行时，操作系统把需要执行的程序和数据调入内存。运行结束后，结果再写回外存。

虚拟内存的思想是：
 在磁盘上开辟一部分空间，把它组织得像内存一样，让程序感觉自己拥有比物理内存更大的地址空间。

虚拟内存的好处：

可以在较小物理内存中运行较大的程序；
 可以让更多程序并发运行；
 程序员不必直接管理内存和外存交换；
 用户看到的虚拟地址空间通常大于真实物理内存。

但注意：磁盘比内存慢很多。如果频繁发生页面换入换出，会导致系统明显变慢，这种现象叫抖动或 thrashing。

## 十、输入输出系统 I/O

输入设备用于把人的命令和数据输入计算机，例如键盘、鼠标、触摸板、摄像头、扫描仪等。

输出设备用于把计算结果展示给用户，例如显示器、打印机、音箱等。

### 1. 端口与接口

端口是连接输入/输出设备的物理接插件。常见端口包括 USB、音频接口、显示接口、键盘鼠标接口等。

数据传输有两类：

**并行传输**：一次传输多位，例如一次 8 位。
 **串行传输**：一次传输 1 位。USB 就是通用串行总线。

### 2. USB

USB 是一种总线标准，也是一种接口技术。

特点：

支持热插拔；
 可以自动配置设备；
 可以通过 USB 线供电；
 理论上最多可以连接 127 个设备。

### 3. 接口的作用

接口用于解决高速主机和低速外设之间速度不匹配的问题。
 接口一端连接 CPU、内存和内部总线，另一端连接外部设备。

### 4. 设备分类

操作系统中常把设备分为：

**块设备**：以固定大小的数据块为单位读写，例如磁盘。
 **字符设备**：以字符流为单位输入输出，例如键盘、鼠标。

## 十一、操作系统 OS

操作系统是计算机硬件与其他软件之间的接口。它负责管理计算机硬件和软件资源，使用户和应用程序能够方便地使用计算机。

一句话理解：

**操作系统 = 资源管理者 + 用户接口 + 程序运行环境**

### 1. 操作系统类型

**实时操作系统**：
 要求在规定时间内响应，常用于航天、工业控制、嵌入式系统等。

**单用户单任务系统**：
 一次只允许一个用户执行一个任务。早期 DOS 属于这一类。

**单用户多任务系统**：
 一个用户可以同时运行多个任务。现代 Windows、macOS 属于这一类。

**多用户多任务系统**：
 允许多个用户同时使用一台主机，并且每个用户可以运行多个任务。UNIX、Linux 服务器常见。

**并行操作系统**：
 面向多处理器系统，需要在多个处理器之间进行任务分配和调度，重点问题包括负载均衡和可扩展性。

**分布式操作系统**：
 管理网络中多个独立计算机，让它们协同工作，实现资源共享和统一控制。

### 2. Kernel 与 Shell

操作系统通常可以分为内核和外壳。

**Kernel，内核**：
 负责最核心的资源管理，例如进程调度、内存管理、设备驱动、文件系统等。

**Shell，外壳**：
 负责接收用户命令，并把命令解释后交给内核执行。Shell 可以是命令行，也可以是脚本方式。

例如 Linux 中的 bash、zsh 就是 shell。

------

## 十二、操作系统的核心功能

操作系统主要有四大功能：

进程管理；
 存储器管理；
 设备管理；
 文件管理。

### 1. 进程管理

**进程 Process** 是正在执行的程序。
 程序是静态的文件，进程是动态的执行过程。

进程管理最重要的任务是进程调度。
 调度的目标是合理分配 CPU 时间，让多个进程看起来能同时运行。

现代操作系统常用时间片轮转等机制。CPU 在很短的时间片内执行一个任务，然后切换到另一个任务。切换速度很快，所以用户感觉多个程序在同时运行。

### 2. 死锁

死锁是指多个进程互相占有对方需要的资源，并且都不释放自己已有资源，导致所有进程都等待下去。

经典形式：

进程 A 占有资源 1，等待资源 2；
 进程 B 占有资源 2，等待资源 1；
 两者都不释放资源，于是系统进入无效等待。

处理死锁可以采用预防、避免、检测和解除等方法。普通用户在 Windows 中看到程序“无响应”，有时可以通过任务管理器强制结束进程。

### 3. 线程

线程是进程内部的轻量级执行流。
 一个进程可以包含一个或多个线程。

进程之间通常拥有独立地址空间；
 同一进程内的多个线程共享该进程的地址空间和资源。

多线程可以提高并发能力，但也会带来数据竞争、锁、同步等问题。

### 4. 存储器管理

存储器管理负责内存资源的分配和使用，包括：

给进程分配内存；
 回收进程释放的内存；
 管理内存和外存之间的数据交换；
 支持虚拟内存；
 进行地址转换和保护。

这里要注意：
 MMU 更准确地说是硬件中的 **Memory Management Unit**，负责地址转换等工作；操作系统的内存管理模块通过页表等机制和 MMU 协同工作。

### 5. 设备管理

操作系统通常不直接操作硬件设备，而是通过设备驱动程序操作设备。

**设备驱动程序 Driver** 是控制和操作设备的软件接口。不同硬件设备通常需要不同驱动。

设备管理提供的功能包括：

设备调度；
 缓冲区管理；
 错误处理；
 设备分配和释放；
 统一的 I/O 接口。

缓冲区的作用是缓解高速 CPU 和低速外设之间的速度差异。

### 6. 文件管理

文件是存储在外存上的、有名字的数据有序集合。
 文件系统负责管理文件和外存空间。

文件系统的功能包括：

创建文件；
 删除文件；
 读写文件；
 复制、移动、重命名文件；
 按文件名查找文件；
 访问控制和权限管理；
 组织外存空间。

Windows 文件名通常可以写成：

```
[盘符:] 文件名 [.扩展名]
```

例如：

```
C:\TEXT.TXT
```

表示 C 盘中的 TEXT 文件，扩展名是 `.TXT`。

扩展名用于帮助操作系统判断文件类型，并关联默认打开程序。例如 `.txt` 常关联文本编辑器，`.docx` 常关联 Word。

通配符：

```
*  表示任意多个任意字符
?  表示一个任意字符
```

例如：

```
*.txt
```

表示所有 txt 文件。

### 7. 文件存取方式

**顺序存取**：
 按照数据单位一个接一个访问，典型例子是磁带文件。

**随机存取**：
 可以根据地址、索引、哈希等方式直接访问目标数据，磁盘文件常见。

**索引文件**：
 先查索引，找到目标数据的存储地址，再访问真实数据。

**哈希文件**：
 用哈希函数把关键字映射到存储地址，提高查找速度。

### 8. 文件存储结构

磁盘通常以扇区或簇作为存储单位。
 一个文件可以占用一个或多个簇。

重点：
 一个簇只要被某个文件占用，即使只存了一点数据，也会被视为整个簇被该文件占用。
 所以文件的“实际大小”和“占用空间”可能不一样。

簇越小，空间浪费越少，但管理开销越大；
 簇越大，管理简单，但小文件可能浪费更多空间。

## 十三、计算机网络与 TCP/IP

### 1. TCP/IP

TCP/IP 是互联网的核心协议族，全称：

**Transmission Control Protocol / Internet Protocol**

其中：

**TCP** 负责可靠传输。
 它会把数据分段、编号、检查错误，并在接收端按顺序重组。如果出错或丢包，可以重传。

**IP** 负责寻址和路由。
 它给每个数据包加上目标地址，让数据包能在网络中传输到目标主机。

简单理解：

```
TCP 关心：数据是否完整、顺序是否正确、丢了要不要重传
IP 关心：数据包往哪里送、经过哪些路由
```

### 2. OSI 与 TCP/IP

OSI 模型是 7 层参考模型，由 ISO 提出。
 TCP/IP 是事实上的互联网标准，通常分为 4 层，比 OSI 更简单。

可以粗略理解为：

```
应用层
传输层
网络层
网络接口层
```

TCP 工作在传输层；
 IP 工作在网络层。

### 3. IP 地址

IP 协议规定，每台入网计算机需要有一个网络地址，即 IP 地址。

拥有 IP 地址的机器叫主机。
 路由器根据 IP 地址转发数据包。

### 4. 私有地址

常见私有 IP 地址范围：

```
10.0.0.0 ~ 10.255.255.255

172.16.0.0 ~ 172.31.255.255

192.168.0.0 ~ 192.168.255.255
```

这些地址只能用于局域网内部通信，不能直接在公网 Internet 上路由。家庭路由器中常见的 `192.168.x.x` 就是私有地址。

如果私有地址中的主机要访问公网，通常需要通过 NAT，也就是网络地址转换。

### 5. 子网与子网掩码

子网是把一个大网络划分成若干个小网络。
 划分子网的好处包括：

便于管理；
 减少广播范围；
 提升网络组织效率；
 可以通过路由器连接不同子网。

子网掩码用于区分 IP 地址中的网络部分和主机部分。

常见默认子网掩码：

```
A 类：255.0.0.0
B 类：255.255.0.0
C 类：255.255.255.0
```

判断两个 IP 是否在同一子网时，要把 IP 地址和子网掩码做按位与运算，得到网络地址。

例如：

```
IP 地址：192.168.1.23
子网掩码：255.255.255.0
网络地址：192.168.1.0
```

如果另一个主机是：

```
192.168.1.45
```

它的网络地址也是 `192.168.1.0`，所以它们在同一子网。

如果另一个主机是：

```
192.168.2.45
```

它的网络地址是 `192.168.2.0`，和前者不同，所以不在同一子网，需要通过路由器转发。

### 6. CIDR

CIDR 是无类别域间路由，Classless Inter-Domain Routing。

它用斜杠表示网络前缀长度，例如：

```
192.168.1.0/24
```

意思是前 24 位是网络部分，剩下 8 位是主机部分。
 `/24` 等价于子网掩码：

```
255.255.255.0
```
