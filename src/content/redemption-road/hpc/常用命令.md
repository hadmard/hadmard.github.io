# 网络代理相关

- `ssh -R 7890:127.0.0.1:7897 yifei@master`
  - 7890是远程服务器的端口，后面的127.0.0.1:7897是本地的端口
- `nano ~/.bashrc`
  - 终端的默认输出端口
- `source ~/.bashrc`
  - 刷新配置

# 安装相关

- `./configure`
  `make`
  `sudo make install`
  - .是当前目录；..是上一级
  - 可执行文件需要./，主要是安全考虑，直接打会去找系统的path
  - sudo make install是安装到系统目录

# 文件操作

- ```
  cp ./bin/Linux_PII_FBLAS/HPL.dat /scratch/hpl_run/
  ```

  - 复制文件到某个目录

- `rm -r mpl`

  - 删除文件夹*mpl*，*-r*是文件夹的意思
