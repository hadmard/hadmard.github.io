期末周无疑是非常痛苦的，对期末的巨大不确定性会使人很焦虑，而这种焦虑很大程度会对个人的作息规律进行冲击。

譬如lz，期末周以来，几乎十几天整体都在学习，早上七八点爬起来，一直学到晚上十点半多，回寝室之后，因为白天的休息缺失，很难控制住不玩手机，所以一般都要一点多甚至更晚入睡。因此不出意外也是遭到了反噬，不仅最近肤色蜡黄，口腔溃疡长了两三个，有一个甚至有点大，导致之前喝水吃东西都会很痛。然后还长了几个“化脓的炎症痘”（GPT说的），昨晚洗完头下楼吹头发，惊奇发现眼中竟然隐隐又些血丝。目前也差不多算是考完了，因此开个健康打卡记录楼，起到一个自律加上部分他律的功能

目前的规划如下：

  1. 夜间睡眠：11:35 - 7：30，先用褪黑素调一调作息，并且提前结束手机的使用，防止addict
  2. 锻炼：尽量保证都有锻炼吧，特殊情况就算了，例如出去玩/下雨但是没有场馆/…
  3. 喝水：每天2L，大约一瓶半水壶的水
  4. …
  5. 按时吃药！

定义

熬夜：指主观和客观的不一致引起的睡眠时间稍晚（例如十二点之后），或者主观和客观一致，但是睡眠时间过晚（例如一点之后）。
