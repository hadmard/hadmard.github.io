线性整流（Rectified Linear Unit）一元逐元素算子。

规格说明

项目内容
算子类型Elementwise（一元）
输入x (float16, ND格式)
输出y (float16, 与输入 shape 相同)
Shape4 维 [N4,N3,N2,N1]（任意维度均可）
计算公式ReLU(x) = max(0, x)
芯片架构Ascend910B (arch22) / Ascend950 (arch35)
精度策略FP16 直算，无需升精度

设计要点

1. 纯 FP16 计算

ReLU 仅是取最大值运算（比较符号位），无精度损失风险，直接在 FP16 域完成。

2. Kernel 实现

Duplicate(zeros, 0, count)   // 填充零 Buffer
Max(y, x, zeros, count)      // y[i] = max(x[i], 0)

3. Tiling

与 abs 算子结构相同（纯 FP16、一元、单输入队列），但额外需要 1 个 TBuf 存放 zeros 常量。

项目AbsReLU
InQueue11
OutQueue11
额外 TBuf01 (zeros)
bufferDivisor（单缓冲）2×2 = 43×2 = 6
bufferDivisor（双缓冲）4×2 = 85×2 = 10

4. 4 维 Shape 适配

Shape元素数核数缓冲模式
[1,16,16,16]40961-2单缓冲
[4,32,32,32]131072多核双缓冲
[8,64,64,64]2097152满核双缓冲
