# v1.41 仓库清理、Apple material 强化与内容添加说明

## 1. 本轮目标

清理当前仓库中不再服务线上 Astro 博客的文件，进一步强化 Apple 官方 material / Liquid Glass 风格，并补齐“以后自己添加内容”的维护说明。

## 2. 背景与上下文

本轮开始前按要求读取了：

- `AGENTS.md`
- `custom/notes/v1.40-blog-reading-and-raw-investment-notes.md`
- 最近相关记录：`v1.38`、`v1.39`、`v1.40`
- 活跃代码：`src/components/`、`src/pages/old/`、`src/styles/global.css`、`src/data/site.ts`、`astro.config.mjs`、`package.json`

没有发现 `custom/notes/experiments/` 目录。本轮延续 v1.40 的个人博客定位，放弃日程、流程图、个人简历、技术栈和 Next 实验站方向。

## 3. 问题分析

仓库存在三类问题：

1. 根目录和 `custom/` 下残留大量历史临时脚本、CC98 抓取中间件、旧设计文档和无关 Conda 环境文件。
2. `next-premium-site/` 作为历史 Next 实验站仍被跟踪，包含 `.next/` 构建缓存和完整 Next 工程，不参与当前发布。
3. 样式里残留流程图、模块控制台、资产卡、时间线等旧类，真实页面只需要博客首页、投资记录、随笔和文章详情样式。

同时，`thoughts` 内容集合已声明，但缺少文章详情路由，用户即使添加 MDX 也不能形成完整阅读链路。

## 4. 候选方案比较

方案 A：只删明显临时文件，不动依赖和样式。优点是风险最低，缺点是 React/Next/旧 CSS 继续污染仓库。

方案 B：清理历史文件、瘦身依赖、重写当前页面所需 CSS。优点是结构清楚，缺点是 diff 较大。

方案 C：重新搭一个全新博客模板。优点是视觉可完全重做，缺点是会丢掉现有 `/old/` 路径、投资记录读取逻辑和 GitHub Pages 产物口径。

最终选择方案 B。

## 5. 最终决策

保留 Astro 主站、`docs/` 发布产物、`custom/cc98-investment-crawler/output/` 投资数据和历史 notes；删除不再参与当前网站的 Next 实验站、临时脚本、无关环境文件和旧 CC98 中间文件。

视觉上参考 Apple 官方 Human Interface Guidelines 与 Apple Design Resources 的 Materials、Motion、Color、SF Pro / SF Symbols / Liquid Glass 方向，但不直接复制 Apple logo、产品图片或受限制营销素材。

## 6. 具体实现

1. 删除历史无用文件：
   - `.bak.LearningMap.tsx`
   - `.vscode/`
   - `DESIGN.md`
   - `environment.yml`
   - `fix_map.cjs`、`rewrite.py`、`scaffold*.cjs`、`script2.js`、`test.cjs`、`update-homepage.js`
   - `next-premium-site/`
   - `custom/cc98-*` 根目录中间抓取文件
2. 移除 React 相关依赖：
   - 删除 `@astrojs/react`、React、React DOM、XYFlow、Framer Motion、Lucide、clsx、tailwind-merge 等不再直接使用的依赖。
   - `astro.config.mjs` 只保留 `mdx()` 和 `sitemap()`。
3. 重写 `src/styles/global.css`：
   - 使用 Apple 平台系统字体栈。
   - 增加系统色、material token、spring/smooth motion token。
   - 保留当前博客实际需要的组件样式。
   - 增加首页三层 `material-layer`、hero glint、错峰 reveal、View Transition 与 reduced-motion 降级。
   - 使用 Tailwind `backdrop-blur-*` 工具类确保产物包含标准 `backdrop-filter`。
4. 补齐随笔内容闭环：
   - 新增 `src/content/thoughts/.gitkeep`。
   - 新增中文详情路由 `src/pages/old/thinking/[...slug].astro`。
   - 新增英文详情路由 `src/pages/old/en/thinking/[...slug].astro`。
   - 随笔列表页自动读取 MDX 集合。
5. 更新维护说明：
   - 重写 `README.md`，说明目录结构、开发发布、Apple 视觉口径、添加随笔和添加投资记录的方法。

## 7. 本轮优点

- 仓库结构显著变轻，主路径只保留当前 Astro 博客需要的东西。
- Apple material 风格更明确：系统字体、系统色、透明材质、标准 `backdrop-filter`、柔和动效都已落地。
- 用户后续可以直接通过 MDX 添加随笔，不需要再改路由。
- 投资记录继续保持“原始记录，只过滤图片和表情”的规则。

## 8. 本轮缺点与代价

- 删除了大量历史实验文件，若以后想回看 Next 实验站，需要从 Git 历史恢复。
- 当前 `src/content/thoughts` 为空，Astro 构建会提示集合未匹配到 MD/MDX 文件；这是预期状态，不影响发布。
- `npm install --package-lock-only` 后 npm audit 仍提示 15 个依赖链安全项，本轮没有做破坏性升级。
