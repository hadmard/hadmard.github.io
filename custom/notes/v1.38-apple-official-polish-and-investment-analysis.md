# 版本记录：v1.38-apple-official-polish-and-investment-analysis

## 1. 本轮目标

根据用户反馈，直接由 Codex 接管前端重构，不再调用 Gemini。目标是把站点从“太素、太空、像半成品”的状态推进到更接近 Apple 官方产品页的质感：首屏更有视觉锚点，技术栈图不再突兀，投资页必须展示真实同步记录与可读分析。

## 3. 问题分析

上一版虽然有四模块结构和液态玻璃外观，但存在三个核心问题：

1. 首页过于空，只有大标题、两枚按钮和玻璃背景，缺少 Apple 产品页常见的“产品可视化对象”。
2. 技术栈页的 ReactFlow 是黑色游戏化面板，和全站明亮 Apple 风格割裂，像突然插入的外部工具。
3. 投资页实际上读取了 CC98 本地记录，但页面只是把原文列表摊开，没有分析摘要、资产聚类和可读时间线，导致用户感觉“没有具体内容”。

## 4. 候选方案比较

方案 A：继续沿用当前页面，只补颜色和间距。
优点是改动很小；缺点是无法解决“空”和“突兀”的结构问题。

方案 B：引入更重的动画库或三维场景。
优点是视觉冲击更强；缺点是当前站点不需要额外依赖，且容易偏离个人主页的真实内容。

方案 C：保持现有 Astro / Tailwind / ReactFlow 技术栈，重写页面结构与视觉层次。
优点是改动集中、可维护、能直接消化已有投资数据；缺点是需要手工细调较多页面。

最终选择方案 C。

## 5. 最终决策

1. 首页重构为沉浸式 Apple hero：使用柔和动态 canvas 背景、四模块控制台、当前快照卡片，减少空白感。
2. 技术栈图改为浅色玻璃路线图：节点、连线、弹层、背景全部统一为明亮风格，并压缩坐标提升可读性。
3. 投资页重写为分析界面：从 CC98 本地同步记录中筛选有效楼层，提取资产标签，构建分析卡、资产面板和具体时间线。
4. 简历与思考页同步换成同一套 feature hero / analysis panel 体系，避免四模块体验割裂。
5. 全过程由 Codex 直接修改，不再调用 Gemini。

## 6. 具体实现

### 6.1 首页

- 重写 `HomePage.astro`：新增四模块 `moduleDeck`，让首页首屏除了标题按钮外还有四个真实入口。
- 将原本的彩色圆点 canvas 改成流动色带 canvas，视觉更像柔和光幕而不是离散光球。
- 新增 `module-console`、`module-tile`、`snapshot-card` 等样式，形成 Apple 风格的产品控制台。

### 6.2 技术栈页

- 重写 `LearningMap.tsx` 的深色节点、连线、tooltip 与弹窗为浅色玻璃 UI。
- 将地图外层由黑色面板改成白色半透明产品截面。
- 压缩 `learningMap.ts` 中所有节点坐标，使 ReactFlow fitView 后节点更大、更可读。
- `progress.astro` 增加 feature hero、说明区与地图上下文，避免路线图突兀进入页面。

### 6.3 投资页

- 重写中英文 `investments.astro`。
- 继续读取 `investment-summary.json` 与 `posts.json`，保留原始同步逻辑。
- 自动过滤 `test`、`记录投资日常` 等无效占位。
- 按 BTC、ETH、XAU、XAG、CRCL、VVV、TAO、美股等关键词提取资产分布。
- 新增分析卡片：主线、风险、规则、宏观四类复盘。
- 新增时间线：展示 14 条有效记录、楼层、时间、资产标签、图表数量和清洗后的正文。

### 6.4 其他模块

- `resume.astro` 改为直接渲染 `copy.resume.timeline`，避免硬编码并提升信息密度。
- `thinking.astro` 改为更精致的编辑队列空态，弱化半成品感。
- 英文页面同步结构，保留投资源内容中的中文原文。

## 7. 本轮优点

1. 首页不再是空白玻璃壳，首屏有动态视觉、明确 CTA 和四模块控制台。
2. 技术栈图和全站风格统一，不再像黑色外部工具。
3. 投资页确实展示了具体内容：14 条有效记录、8 类资产、分析摘要和原文时间线。
4. 没有新增依赖，仍保持 Astro 静态站点结构。

## 8. 本轮缺点与代价

1. 投资页中英文都读取同一份中文源记录，英文页界面已翻译，但原始日志仍是中文。
2. 首页移动端因为四模块控制台内容较多，hero 自然高度变长；这是为了保留信息密度而接受的代价。
3. 投资分析目前是关键词与人工归纳结合，还不是完整交易系统级的数据建模。
