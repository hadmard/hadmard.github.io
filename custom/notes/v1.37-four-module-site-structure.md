# 版本记录：v1.37-four-module-site-structure

## 1. 本轮目标
根据用户要求，彻底取消日程（Calendar）功能，将站点模块精简并重构为四个核心模块：个人技术栈、投资记录分析、个人思考感悟、个人简历（含项目）。同时在保证“Apple 简约风、Liquid Glass、丝滑动画”视觉方向的前提下，梳理导航与各级说明文案。

## 2. 背景与上下文
本轮先读取了：
- `AGENTS.md`
- `custom/notes/v1.36-gemini-apple-liquid-glass-site-redesign.md`
- `custom/notes/v1.35-root-homepage-restore-old-site.md`
- `custom/notes/v1.34-calendar-weekday-fix-and-liquid-glass.md`
- `src/data/site.ts` 及其相关组件与 Astro 页面

当前状态是根首页已经去除了日程展示并切回个人主页内容（v1.35），但仍存在一些历史模块遗留（如独立的 projects 页面），且部分页面的文案需要对齐到全新的四大模块体系。本轮任务由 `gemini-3.1-pro-preview` 模型驱动。

## 3. 问题分析
1. 导航与结构需要严格统一到四个模块：progress -> 个人技术栈；investments -> 投资记录分析；thinking -> 个人思考感悟；resume -> 个人简历（含项目）。
2. 旧的 projects 页面独立存在，需要将其内容整合至 resume，并删除独立的页面文件以满足“只留四个模块”的硬性要求。
3. Astro 子页面中存在一些硬编码的文案（例如“学习进度”、“test”占位符），需要统一通过 `site.ts` 的结构化数据进行替换。
4. 首页的 CTA 原本为无动作的 span，需要指向“个人技术栈”与“投资记录分析”。

## 4. 候选方案比较
**关于项目页面的处理方案：**
- 方案 A：保留 projects Astro 文件，但从导航隐藏。
- 方案 B：彻底删除 projects Astro 文件，确保产物中不含冗余模块，将其相关说明字段整合进 `site.ts` 的 `resume` 对象并在简历页渲染。
最终决策：方案 B，符合“只留四个模块”且架构最精简。

**关于文本替换方案：**
- 方案 A：在 Astro 文件内直接修改硬编码文字。
- 方案 B：全面更新 `site.ts` 并使 Astro 页面引用 `copy.xxx` 获取内容，提升维护一致性。
最终决策：方案 B，进一步收敛文案配置。

## 5. 最终决策
1. 重构 `src/data/site.ts`，定义全新的 4 个模块导航，更新首页 CTA 文案和指向，并将 projects 说明合并入 resume。
2. 删除 `src/pages/old/projects.astro` 与 `src/pages/old/en/projects.astro`。
3. 修改四个对应子页（包括中英文）的 Astro 模板，使其获取新的结构化文案，移除原有的占位硬编码文本。
4. 将首页 CTA span 修改为真实可点击的 `<a>` 链接。

## 6. 具体实现
- **`site.ts`**：
  - 更新 `nav` 数组为 4 项。
  - 将 `projects` 字段移除，并在 `resume` 结构中新增 `projectsTitle`、`projectsIntro`、`projectsEmptyTitle`、`projectsEmptyDescription` 字段。
  - 更新了所有对应的中英文说明。
- **页面清理**：执行 `rm -f src/pages/old/projects.astro src/pages/old/en/projects.astro` 删除独立的 projects。
- **`HomePage.astro`**：将 `primaryCta` 和 `secondaryCta` 替换为包裹 `<a>` 的标签，动态生成指向 `progress` 和 `investments` 的 href。
- **子页面重构**：更新了 `progress.astro`、`thinking.astro`、`investments.astro` 的头部展示，使其从 `site.ts` 取值；在 `resume.astro` 底部追加了项目经历的展示区域。所有操作在中英双语页面同步进行。

## 7. 本轮优点
- 系统架构高度收敛：彻底移除了不再需要的项目页面与日历残留功能。
- 数据与视图进一步解耦：此前写死在 Astro 文件里的标题与描述都被抽离到了 `site.ts`。
- 导航链路与交互更清晰：首页通过明确的 CTA 直接引导用户进入核心关注点。

## 8. 本轮缺点与代价
- 简历页内容变长，由于项目暂时为空态，底部展示的都是预期规划内容。
- 已知的“thoughts 集合为空”的 Astro 构建警告依然存在（由于内容尚未填充），这属于正常预期内。

## 9. 验证与结果
- 成功执行了 `npm run build`，构建耗时约 23 秒。
- 删除了 2 个 projects 页面，静态页面产物从 13 个缩减为 11 个，验证通过。
- 未引入任何新依赖、新样式表或额外的工具配置文件。

## 10. 本轮结论
成功通过 `gemini-3.1-pro-preview` 模型完成四模块架构重组。系统功能变得更加聚焦，Apple Liquid Glass 风格得到了保留，且不存在任何日历/日程相关遗留。
