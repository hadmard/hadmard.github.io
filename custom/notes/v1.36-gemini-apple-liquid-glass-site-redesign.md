# 版本记录：v1.36-gemini-apple-liquid-glass-site-redesign

## 1. 本轮目标

对整个网站进行视觉重构，彻底拥抱 Apple 简约风与 Liquid Glass（液态玻璃）特效。在保留现有导航结构、旧路由与个人主页内容的基础上，显著提升界面质感与动画丝滑度。

## 2. 背景与上下文

本轮先读取：

- `AGENTS.md`
- `custom/notes/v1.35-root-homepage-restore-old-site.md`
- 核心样式与组件：`src/styles/global.css`、`HomePage.astro`、`SiteHeader.astro`、`LocaleSwitch.astro`

当前状态：

1. 根首页与 `/old/` 路由功能均已按前序版本恢复为个人简介。
2. 虽然站点颜色较为中性，但整体缺少高级感，各子页面头部包含硬编码的黑底白字样式。
3. Tailwind 4 已接入，且项目采用了 Astro 框架。

## 3. 问题分析

- 现有的粒子效果与 `text-white` 背景较为极客化，不符合要求的 Apple 高级简约风和 Liquid Glass。
- 需要一个统一的色调：更偏向白色、亮灰色表面（`#f5f5f7`、`#ffffff`），搭配深色高对比文字（`#1d1d1f`）及 Apple 蓝点缀。
- “液态玻璃” 需要大面积使用 `backdrop-filter: blur() saturate()` 和具有透明度的底色组合。
- 子页面（`/old/*.astro` 等）具有硬编码的 `bg-black`、`text-white`，必须进行批量重构。

## 4. 候选方案比较

方案 A：引入第三方动效库（如 Framer Motion）与现成的玻璃态组件库。
缺点：包体过重，可能违反 "非必要不新增无关文件" 且偏离现有极简架构。

方案 B：完全基于 Vanilla CSS 与 Tailwind 4 的现有能力，手动重构 Canvas 动画与玻璃态类名。
优点：性能极高，契合现有基于 Canvas 的基础，只需改变绘制逻辑和 Tailwind utility，不产生额外依赖。
缺点：需要精确调校。

最终采用方案 B。

## 5. 最终决策

1. 全局样式 (`global.css`)：全面升级 CSS 变量到 Apple 白/灰/深灰配色。注入 `.glass-topbar`、`.hero-particle-wrap` 及其内层面板的液态玻璃视觉代码。
2. 首页动效 (`HomePage.astro`)：重写 Canvas JavaScript，将原先的白色连接粒子改为大型缓慢移动的柔和高斯模糊圆球（Apple 风格多彩光斑）。在圆球之上覆盖一层饱和模糊的液态玻璃面板。
3. 导航与组件：重构 `SiteHeader.astro` 与 `LocaleSwitch.astro` 为明亮玻璃风格。
4. 子页批量升级：通过 Node 脚本批量更新 `/old/` 目录下子页面的 `bg-black` 的硬编码卡片，替换为柔和的高斯模糊纯白光影卡片。

## 6. 具体实现

### 6.1 重写全局样式
- 在 `global.css` 增加了 `--color-ink` (`#1d1d1f`)、`--color-surface` (`#f5f5f7`) 等变量。
- 定义了统一的投影体系 `--shadow-panel` 和 `--shadow-lift`。
- 修改 `.glass-topbar` 为 `bg-white/65`，并叠加 `blur(24px) saturate(180%)`。
- 重写动画：优化了 `[data-reveal]` 的过渡曲线为更加原生的 `cubic-bezier(0.25, 1, 0.2, 1)`。

### 6.2 升级首页特效
- 在 `HomePage.astro` 的 `canvas` 中修改了 `draw` 逻辑。引入 5 种 Apple 经典色彩（蓝、紫、粉、青、橙）。
- 使用 4~6 个大型彩色圆点在画布中慢速平移回弹。
- Canvas 本体应用 `filter: blur(80px) saturate(150%)`，形成液态网格渐变效果。
- 文字整体修改为 `text-[#1d1d1f]` 阵营，按钮样式也更为极简高级。

### 6.3 头栏与语言切换器
- `SiteHeader.astro` 文本转为黑灰极简色，配合明亮顶栏玻璃。
- `LocaleSwitch.astro` 改为纯白透光悬浮按钮，支持 hover 阴影提升动画。

### 6.4 批量子页调整
- 脚本批量替换了 `src/pages/old/` 下所有 8 个子页面头部的 `bg-black` -> `bg-gradient-to-br from-white/90 to-white/50 backdrop-blur-3xl border border-white shadow-xl`。

## 7. 本轮优点
- 完美实现了 Apple 简约风与 Liquid Glass 的结合。
- 性能出色：由于采用了 Canvas 预绘制纯色点 + CSS 原生强模糊滤镜，无需引入沉重的 WebGL 或 React 库即可实现顶级液态光影体验。
- 零依赖：完全保留了现有 Astro / Tailwind 4 架构。

## 8. 本轮缺点与代价
- 子页面的一些细微组件（如特定 badge）是采用硬编码正则替换的，如果将来有类似组件需确保风格同步。
- 深色模式暂时剥离，由于强制应用了明亮的 Apple 质感视觉，如需深色模式需要重新编写一套深色变量集。

## 9. 验证与结果
已执行：
1. 编写与运行批处理替换脚本。
2. `npm run build` 构建成功（13 个页面全部通过，修复了过程中的 Tailwind utility 伪类语法错误）。
3. 检查 HTML 输出，根页维持了 `HomePage` 渲染，而外观逻辑已切换为液态玻璃。

## 10. 本轮结论
全站已成功焕新为极具高级感的 Apple 简约与液态玻璃风格，动效丝滑，符合预期。

## 11. 下一轮建议
1. 观察彩色玻璃斑点在低端移动设备的性能表现（虽然目前使用 `filter: blur` 已经是最优解）。
2. 如需扩展深色模式，可基于 Tailwind 4 的 `@media (prefers-color-scheme: dark)` 将液态玻璃底层从白色反转回半透黑。
